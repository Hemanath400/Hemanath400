- **Metrics:** 90.1% mAP@50 · 100% Precision · 90% Recall · 94.7% F1  
- **Stack:** <img src="https://skillicons.dev/icons?i=py,opencv" height="20" /> `Python` · `RF-DETR` · `Roboflow` · `OpenCV`
