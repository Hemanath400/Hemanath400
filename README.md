# 🚀 Featured Projects

### 🥇 Rumble Strip Detection

**Computer Vision • Object Detection • Real-time Warning**

[![Rumble Strip Detection](https://img.shields.io/badge/View%20Project-Repository-181717?style=for-the-badge\&logo=github)](https://github.com/Hemanath400/rumble-strip-detection)

</div>

A computer vision system designed to detect **highway rumble strips from
forward-facing road video** and provide an early warning before the vehicle
reaches them.

### 📈 Model Results

```text
mAP@50       → 90.1%
Precision    → 100%
Recall       → 90.0%
F1 Score     → 94.7%
Unseen Tests → 3/3 detected
```

### 🔬 Pipeline

```text
Highway Videos
       │
       ▼
Frame Extraction
       │
       ▼
Dataset Construction
       │
       ▼
Bounding Box Annotation
       │
       ▼
RF-DETR Training
       │
       ▼
Validation
       │
       ▼
Unseen Highway Video Testing
       │
       ▼
Temporal Confirmation
       │
       ▼
Driver Warning Prototype
```

### 🛠️ Technologies

`Python` `Computer Vision` `RF-DETR` `Roboflow`

# 🏗️ How I Approach ML Projects

I try to build projects around the complete engineering lifecycle.

### 01 — Understand the Problem

```text
What problem are we solving?
Who benefits from the solution?
What does success mean?
```

### 02 — Build the Dataset

```text
Data Collection
Data Cleaning
Data Annotation
Data Validation
Feature Engineering
```

### 03 — Train & Experiment

```text
Baseline Model
        ↓
Model Selection
        ↓
Training
        ↓
Hyperparameter Tuning
        ↓
Evaluation
```

### 04 — Validate Properly

```text
Validation Dataset
        +
Unseen Data
        +
Real-world Testing
```

### 05 — Deploy

```text
Model
 ↓
API / Application
 ↓
User Interface
 ↓
Inference
```

### 06 — Iterate

```text
Measure
 ↓
Identify Weaknesses
 ↓
Improve Dataset / Model
 ↓
Retest
```
